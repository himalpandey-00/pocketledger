# PocketLedger

Personal income and expense tracker. Static, client-side progressive web app optimized for iPhone.

## Privacy
Financial transactions remain in the browser's localStorage on each device. GitHub stores only the source code. No server, login, or synchronization. Export JSON backups regularly and keep them in a safe private location. Do not commit financial data files or backups to this public repository.

## Deployment
In GitHub repository Settings → Pages, set Build and deployment to **Deploy from a branch**, choose **main** and **/(root)**, then Save. Open https://himalpandey-00.github.io/pocketledger/ on Safari and use Share → Add to Home Screen.

## Features
Income and expense entries, category breakdowns, searchable monthly transactions, monthly budgets, CSV export, backup and restore.
